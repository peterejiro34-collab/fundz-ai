# Fundz-AI 💰

AI-powered budget tracker built with React + Vite + Tailwind

### Features
- Track income & expenses in Naira ₦
- AI budget tips based on spending habits
- Data saves to localStorage
- Clean dark UI

### How to Deploy to GitHub

Run these commands one by one in your `fundz-ai` folder:

```bash
git init
git add .
git commit -m "Initial commit: Fundz-AI"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/fundz-ai.git
git push -u origin main
